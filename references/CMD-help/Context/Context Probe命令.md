**Context \-- Context Probe命令 \-- debugging system internal sib sflow**

------------------------------------------------------------------------

**[debugging system internal sib flow**]命令用来打开非缺省context下引流规则的调试开关。

**[undo debugging system internal sib flow**]命令用来恢复缺省情况。

【命令】

**[debugging system internal sib flow**]

**[undo debugging system internal sib flow**]

【缺省情况】

非缺省context下引流规则的调试开关处于关闭状态。

【视图】

Probe视图

【缺省用户角色】

network-admin

mdc-admin

【使用指导】

请登录非缺省Context，在非缺省Context下配置该命令。缺省Context下不支持该命令。
