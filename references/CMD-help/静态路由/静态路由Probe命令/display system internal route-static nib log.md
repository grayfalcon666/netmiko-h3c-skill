
**静态路由 \-- 静态路由Probe命令 \-- display system internal route-static nib log**

------------------------------------------------------------------------

**[display system internal route-static nib log**]命令用来显示静态路由NIB子模块日志信息。

【命令】

**[display system internal route-static nib log** [ **reverse** ]]

【视图】

Probe视图

【缺省用户角色】

network-admin

mdc-admin

【参数】

**[reverse**]：按时间新旧显示日志信息。

【命令】

**[reset system internal route-static nib log**]

【视图】

Probe视图
